## 🚀 Tech Stack

The platform is built with a focus on high-performance 3D graphics, seamless animations, and modern web standards:

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **3D & Canvas:** [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://gsap.com/)
- **Smooth Scrolling:** [Lenis](https://lenis.darkroom.engineering/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## 🛠️ Local Development

### Prerequisites
- Node.js (v20 or higher recommended)
- npm, yarn, pnpm, or bun

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vcethackathon/vcet-hackathon-26.git
   cd vcet-hackathon-26/client
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📁 Project Structure

```text
vcet-hackathon-26/
└── client/
    ├── app/               # Next.js App Router (pages, layouts, global styles)
    ├── components/        # React Components
    │   ├── layout/        # Navbar, Footer, etc.
    │   ├── models/        # 3D Models & React Three Fiber components
    │   ├── sections/      # Page sections (Hero, Timeline, Prizes, etc.)
    │   └── ui/            # Reusable UI elements
    ├── config/            # Centralized site configurations (site.ts)
    ├── public/            # Static assets (images, 3D models, fonts, videos)
    └── styles/            # CSS Modules & global styles
```
