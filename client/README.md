# VCET Hackathon Arcade

A scalable Next.js starter for the VCET Hackathon landing page, built with an arcade-inspired neon theme and advanced UI motion.

## Setup

1. Install dependencies

   ```bash
   npm install
   ```

2. Run development server

   ```bash
   npm run dev
   ```

3. Open `http://localhost:3000`

## Structure

- `app/layout.tsx` — global layout and metadata
- `app/page.tsx` — landing page composition
- `components/Hero.tsx` — hero section with arcade motion
- `components/FeatureCard.tsx` — reusable section cards
- `app/globals.css` — global neon theme styles

## Theme colors

- Hot Magenta: `#FF007F`
- Arcade Cyan: `#00F0FF`
- Neon Purple: `#8A2BE2`
- Quarter Gold: `#FFD700`
- Midnight Black: `#0B0C10`
